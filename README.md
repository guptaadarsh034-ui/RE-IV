# re-iv

Touch-control frontend and performance profiles for running a **legally owned** copy of GTA IV on Android through a Windows compatibility layer (e.g. GameHub, Winlator).

> ⚠️ Experimental. No game files, ISOs, firmware or Rockstar/Microsoft assets are included or distributed. You must supply your own legal copy.

## Features
- Customizable on-screen touch controls
- Gamepad/controller support
- Preset performance profiles
- Built automatically via GitHub Actions

## Requirements
- Minimum: Snapdragon 6 Gen 1 class, 8 GB RAM, Android 12+ (community-reported 15-22 fps on low settings)
- Recommended: Snapdragon 8 Gen 2+, 12 GB RAM
- ~25 GB free storage
- Your own legal copy of GTA IV (Complete Edition recommended)

## Build
1. Fork the repo
2. Open the **Actions** tab, run **Build APK**
3. Download the APK from **Artifacts**

## Low-end profile (6 Gen 1 / 8 GB)
- Resolution: 640x360 or 800x450
- DXVK 2.x, latest Turnip driver
- Box64 preset: performance, CPU affinity on big cores
- Close background apps and keep the device cool
- In-game: low textures, view distance 1-5, detail 1-5, shadows off, vsync off
- FusionFix installed, FPS cap at 24-30
